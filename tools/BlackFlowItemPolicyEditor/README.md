# 黑流 N6 物品策略编辑器

运行 `python tools/BlackFlowItemPolicyEditor/server.py`，打开终端输出的本地地址。
默认地址为 `http://127.0.0.1:8876`，仅监听本机。

四个页签分别编辑购买、出售、战利品选择与库存过载取舍。出售只设置各店是否出售与
最低售价，不设额外的保护属性。旧草稿会把保护折算为两店都不出售，并移除旧字段；
其他设置、排序、备注及检查点保留。已有规则来自当前采集器，
新增物品显示为待确认。支持拖动、上下移动、直接输入位置、按参照物插入、搜索、
新增/待定筛选、单项还原、撤销/重做、保存检查点和 JSON 草稿导入导出。

修改自动写入本目录的 `draft.json`，重开页面从该文件恢复。右下角显示实际磁盘保存
状态；保存失败时保留浏览器中的修改，并可导出 JSON。草稿保留稳定 ID、源文件
指纹、四张策略表、排序、备注、确认状态与检查点。`draft.json` 不纳入 Git。

本工具只保存策略草稿，不直接覆盖 C++、tasks.json 或运行实例。N16、险路尽头、
其他分队和完整结局支持均不在本次编辑范围。四件结局藏品不作为常规购买条目。

`index.html` 是自包含的编辑页面，包含本地 React 运行时，无外部网络依赖。
编辑视图对应本工作区 `blackflow-n6-item-policy.canvas.tsx`，生成版本的基线为
`blackflow-n6-2026-10-18-v1`；`server.py` 只提供页面和固定草稿文件的读写。

2026-10-20 保存的 N6 草稿已应用到源码，批准内容与原草稿 SHA256 固定在
`unit_test/MaaCore/fixtures/blackflow-item-policy/approved-n6.json`，供策略回归使用。
编辑器仍保留原比较基线和用户草稿，后续调整继续自动保存，不自动覆盖源码。
