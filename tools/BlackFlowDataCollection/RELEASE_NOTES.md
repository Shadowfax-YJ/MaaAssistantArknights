黑流树海采集版 v1.1.20

### 本次更新

* Windows 和 macOS 的国内自动更新与安装包下载改用 `cdn.lubiao.wiki`。

### 升级

* v1.1.2 及以上版本可在采集版内检查更新，下载后按提示重启安装，保留已有连接设置、任务配置和采集数据。
* 如果旧版本无法从国内源检查更新，可暂时将更新源切换为 GitHub，或使用下方完整包升级。
* Windows 旧版若无法启动，或使用 v1.1.1 及更早版本，请完全退出 MAA 后，将新版完整包解压覆盖到原采集版目录，无需重新配置。
* macOS 手动升级时，退出 MAA，将 DMG 中的应用替换到原来的 Applications 位置。首次打开若被系统拦截，请在访达中右键 MAA 并选择“打开”。

### 下载

* [Windows x64 国内下载](https://cdn.lubiao.wiki/maa/blackflow/v1.1.20/MAA-BlackFlow-Data-Collection-v1.1.20-win-x64.zip)
* [macOS 通用包国内下载](https://cdn.lubiao.wiki/maa/blackflow/v1.1.20/MAA-BlackFlow-Data-Collection-v1.1.20-macos-universal.dmg)

提交数据时，请直接上传 `debug/BlackFlow` 中程序自动生成的原始 ZIP，不要修改内容或重新压缩。
