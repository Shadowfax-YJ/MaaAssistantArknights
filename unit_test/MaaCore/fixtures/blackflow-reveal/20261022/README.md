# 视野核对现场样本

`captured-cases.json` 来自 MAA-002 在 2026-10-22 的四局运行：
`run-20261022-162125-048025`、`run-20261022-125949-458612`、
`run-20261022-101938-443862`、`run-20261022-091905-950294`。
保留了八次弥散虚雾告警及一次和平守卫者告警的地图节点、身份来源、标记、
连线、实际落点、移动前状态和当时识别出的理想域；删除无关的绘图及候选路线详情。
未来才确认的理想域不注入早期未知样本。

`BlackFlowRevealReplay.h` 用这些观测驱动真实 Session 的合并、提交、页面结果和
回图核对。页面回调及控制器响应为受控输入，地图数据来自现场；不表示已经完成
新版实机整局验证。旧核心在最初四个代表用例上全部误报。

`producer-events.json` 是修复后九个 Session 用例输出的诊断载荷，事件封套为合成
元数据。它由独立签名归档验证器和 analysis 消费者共用，不产生新的节点访问、
交易或实际揭示事实。未确定的范围与明确不一致分开；原始截图与历史日志不改写。
