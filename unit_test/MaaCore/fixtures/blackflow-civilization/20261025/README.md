# 复原文明专用扫描回放

23 组来源 / 127 张未改动原图（DLC0 16 组；DLC1 7 组重复末页），来自交接工单所引审计清单。
`sources.json` 保留包路径、成员、原事件、原图 SHA-256、独立人工复核的自然物多重集合；
只复制原图到便携路径，没有改原包或历史分析账本。原始核查路径作为出处字符串保存，不参与运行时寻址。

`observations.json` 是生产 ResourceLoader、PipelineAnalyzer、OCRer 在这些原图上的实际模型输出，
包括展开/开箱/详情模板、容量、完整名称过滤结果，以及不限词表的原 OCR 和明确空槽。
`recognition-recipe.json` 固定模型、识别代码和任务配置；契约测试检查其 SHA-256。
回放提取实际 `scan_sacrifice_natural_items` / `report_sacrifice` 方法，只注入识别输出、控制器、等待和存储边界。
每次原生回放另运行当前生产识别，验证详情浮层阳性/普通库存阴性及六空槽的真实 OCR。

CIV-01/02 修改前真实生产方法回放为 8 失败 / 1 通过，失败包括五组 O/12 空箱、扫齐关箱失败、
失败原帧丢失；短滑当时已会被最终数量不等拒绝，不能称为旧版完全没有保护。
新回放覆盖五组 11 件全扫齐、五组明确空箱、四组开关失败原图、真实短滑、详情遮挡、
同名实例/不同描述、重复视野、未知/缺容量/存储失败、同槽冲突身份，以及七组 DLC1 前后页与人工清单。
新 complete 必须与复核的实际槽位多重集合一致，否则须保留具体失败证据。
完全相同的同名同图视野不能证明移动，保持 unknown；不以总数或预期消耗两件补齐。

关闭失败、输入失败及未知名称使用受控边界，不是新实机重现；同名实例测试只替换识别输出，
保留真实旧图的描述/列移动；既没有修改原图，也没有声称原图实际物品全部同名。
空箱使用原始 O/12 + 六个明确待收集槽位；失与得交换选物页的空列表是另一套已有回放。
本目录没有新版实机跑局样本。
