# Triage Labels

The skills use five canonical triage roles. This table maps each role to the label used in this repository.

| Canonical role    | Tracker label     | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and AFK-ready            |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

When a skill refers to a triage role, use the corresponding tracker label from this table.
