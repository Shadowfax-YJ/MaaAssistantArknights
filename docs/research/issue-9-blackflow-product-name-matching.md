# 黑流商店商品名归一化与模糊匹配结论

> 对应票据：[用样本锁定商品名归一化与模糊匹配规则](https://github.com/Shadowfax-YJ/MaaAssistantArknights/issues/9)  
> 日期：2026-07-20（Asia/Shanghai）  
> 范围：规划与规则验证，不实现生产功能。

## 标准商品名词典

上游固定版本仍提供 365 个逐码点名称，但末尾由 U+002D 连字符和单个希腊字母组成的商品变体后缀不参与区分。对上游名称做 NFC、去除此类后缀并逐码点去重后，得到 326 个标准商品名，见 [`issue-9-blackflow-standard-product-names.txt`](issue-9-blackflow-standard-product-names.txt)。该文件按 ordinal 顺序、UTF-8、LF、无尾随 LF 连接时的 SHA-256 为 `48972fc3a5b40a6586b2707f14c5e73ccf23dfaf0a25cea121b5e273684f7a50`。

`凉拌海草-α`、`凉拌海草-β`、`凉拌海草-γ` 以及同形的其他希腊字母变体都归并为 `凉拌海草`。没有 U+002D 连字符的 `沙盘α`、`沙盘β` 不属于商品变体后缀，必须保留为两个不同标准商品名。

## OCR 归一化白名单

原始 OCR 文本可作为审计证据原样保留；进入标准商品名匹配的派生文本只允许依序执行：

1. Unicode NFC。
2. 删除 Unicode 空白。
3. 去除末尾 U+002D 连字符加单个希腊字母的商品变体后缀。
4. 对成对 ASCII 双引号尝试转换为 U+201C/U+201D；只有转换结果能精确命中词典时才采用，否则回到转换前文本继续判断。

禁止 NFKC、大小写折叠、任意标点删除、横线等价或希腊字母与拉丁字母互换。这些差异若没有被上述白名单处理，只能作为普通 Unicode 码点差异进入模糊匹配。

## 匹配规则

OCR 分数先满足对应路径的下限：

- 精确命中（含成功的受控引号转换）：`score >= 0.75`，结果标记为 `exact`。
- 模糊修复：`score >= 0.85`，结果标记为 `fuzzy`。
- 低于下限或无法可靠匹配：保留 OCR 原文并标记为 `unmatched`。

精确命中不应用候选领先差距。非精确输入按 Unicode 码点计算 Levenshtein 距离，最大编辑数取决于候选标准商品名长度：

| 标准商品名长度 | 最大编辑数 |
| ---: | ---: |
| `<= 3` | 0 |
| `4–7` | 1 |
| `>= 8` | 2 |

模糊修复还必须满足 `第二候选距离 - 第一候选距离 >= 2`；否则一律 `unmatched`。

## 样本与扰动验证

当前 Word OCR 模型对八张商店总览快照的十个固定商品槽位逐槽识别：

- 70 个非空槽全部得到正确标准商品名，10 个空槽全部保持未匹配。
- 非空标题最低 OCR 分数为 `0.865232`；空槽重复标点噪声最高为 `0.599459`。
- 唯一需要受控归一化的真实输出是 ASCII 引号形式的 `"老妈的鼓励"`。
- 人工真值中的 `审天源石虫`、`断枝-波纹` 经截图与固定词典复核后分别修正为 `窜天源石虫`、`断杖-波纹`。

对 326 名词典进行自动扰动：

- 5,252 个单码点删除、插入或替换案例：正确模糊修复 3,936，保守拒绝 1,315，错误模糊修复 0；另有 1 个精确碰撞。
- 688 个长名称双码点替换案例：正确模糊修复 444，保守拒绝 244，错误模糊修复 0。
- 后缀探针确认 `凉拌海草-α/-β/-γ/-δ` 都归并为 `凉拌海草`，而 `沙盘α`、`沙盘β` 分别精确命中自身。

正式验收必须固定真实 80 槽回归、分数边界、长度边界、后缀归并、无连字符希腊字母区分、同距候选和候选领先不足等案例，并断言错误 `fuzzy` 修复数为 0。

## 能力边界

纯字符串匹配无法发现 OCR 恰好落在另一个有效标准商品名上的错误。例如真实文本若是 `犬植浆`、OCR 恰好输出 `植浆`，该输出会按已确认规则成为 `植浆` 的 `exact` 命中。该边界必须在规格中明确；候选领先差距只约束 `fuzzy`，不能声称消除此类精确碰撞。
